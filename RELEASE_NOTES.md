# SnapPocket v1.0.0

## 中文

SnapPocket 的首个正式版。用快捷键截图、标注或置顶，并为不同应用和游戏记住各自的截图保存目录。

- 支持区域、全屏、活动窗口和滚动长截图。滚动时可预览拼接结果。
- 将截图贴在其他窗口上方，方便对照内容。
- 截图后可添加箭头、文字、步骤编号、马赛克或模糊，也可以在保存前改名。
- 支持 PNG、JPG 和 WebP，可自定义快捷键。普通截图会保存到本地并尝试复制到剪贴板。

在下方下载 `SnapPocket-win-x64.zip`，解压后运行 `SnapPocket.exe`，按 `Ctrl + Shift + 1` 开始截图，按 `Ctrl + Shift + 6` 打开悬浮面板。便携包适用于 64 位 Windows 10 和 Windows 11，自带 .NET 运行时。`SHA256SUMS.txt` 用于校验下载。

完整快捷键和使用方法见 [中文 README](https://github.com/ei4869/SnapPocket/blob/v1.0.0/README.md)。

## English

The first stable release of SnapPocket. Capture, annotate, or pin screenshots with keyboard shortcuts, and keep separate screenshot folders for your apps and games.

- Capture a region, the full screen, the active window, or a scrolling area with a live stitching preview.
- Pin screenshots above other windows for easy reference.
- Add arrows, text, step numbers, pixelation, or blur, and rename a screenshot before saving.
- Save as PNG, JPG, or WebP and customize keyboard shortcuts. Regular captures are saved locally and copied to the clipboard when available.

Download `SnapPocket-win-x64.zip` below, extract it, and run `SnapPocket.exe`. Press `Ctrl + Shift + 1` to capture a region or `Ctrl + Shift + 6` to open the floating panel. The portable package includes the .NET runtime for 64-bit Windows 10 and Windows 11. The app interface is in Simplified Chinese. Use `SHA256SUMS.txt` to verify the download.

See the [English README](https://github.com/ei4869/SnapPocket/blob/v1.0.0/README.en.md) for the full shortcut list and instructions.
